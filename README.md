# Number System Calculator

A Java-based calculator that performs basic arithmetic operations and number system conversions. It also includes a simple GUI made using Java Swing.

## Features

* Basic arithmetic operations

  * Addition
  * Subtraction
  * Multiplication
  * Division
  * Remainder
* Number system conversions

  * Decimal to Binary
  * Decimal to Octal
  * Decimal to Hexadecimal
  * Binary to Decimal
  * Octal to Decimal
  * Hexadecimal to Decimal
* Number system calculations
* Supports positive and negative results
* Checks if a number is even or odd
* Checks if a number is prime
* Calculation history
* Dark-themed GUI

## Technologies Used

* Java
* Java Swing
* Object-Oriented Programming (OOP)

## How to Run

1. Clone or download the repository.
2. Open the project in a Java IDE.
3. Run `NumSysCalc.java`.
4. Use the buttons and modes to perform calculations.
